# PROBLEM SOLVING AND PROGRAMMING

A university group project developed for **[PROBLEM SOLVING AND PROGRAMMING]** at TAR UMT.

## Project Information

- **Programme:** Diploma in Information Technology
- **Year / Semester:** Y1S1

## Overview

This project is a C++ waffle ordering and sales management system for a café or food stall. It allows staff to take customer orders by flavor and quantity, calculate total payable amounts, and choose a payment method. It also includes a reporting section that shows sold quantities and a simple sales graph for each waffle type.

## Features

- Order entry for multiple waffle flavors and quantities
- Automatic total cost and payment summary for each customer
- Payment method selection for cash, e-wallet, credit card, or debit card
- Sales reporting with total sold items and revenue tracking
- Simple graphical sales display for each waffle flavor

## Disclaimer

This project was developed as part of university coursework at TAR UMT.
